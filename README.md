# 小本本 (XiaoBenBen)

一款基于 Kotlin 与 Jetpack Compose (Material Design 3) 构建的 Android 智能通知自动记账与多账本管理应用。

- **当前版本**：`v1.1.4.529`
- **包名**：`com.live150yo.lvshuiqingshan`
- **系统要求**：Android 11 (API 30)+ · Target Android 17 (API 37)
- **开源协议**：MIT License

## 基本功能介绍

- **自动通知识别与规则学习**：监听自定义选择的微信、支付宝、短信、各大银行及其他已安装应用通知，自动识别中文/外币金额单位并精准提取多金额通知中的主交易金额，自动忽略不含有效金额的通知；支持自定义关键词/模版规则、非账单忽略规则与可配置保留策略的持久化通知读取日志。
- **AI 理解增强**：支持本地开源小模型权重与在线 OpenAI 兼容 API，自动联动自定义分类、渠道与账单扩展字段，辅助解析复杂通知。
- **账单管理与多账本**：支持吸顶多关键词搜索（含日期、时段、金额与全部扩展字段）、分批加载、长按多选批量操作、智能去重、相似账单联动修改、独立多账本明细与横滑分析，以及全局操作一键撤回。
- **分类、渠道与账单字段定制**：支持分类/渠道父子折叠归属、长按拖动排序与悬停高光归属、无损切换账单显示子类/父类名、快捷查看关联账单、自定义分类图标，以及自定义账单可选信息类别与折叠排序。
- **多维度收支分析与多币种汇率**：提供年/月/周/日统计、圆环图、手势跟随过渡的全屏收支日历与交互式趋势图（柱状/折线/面积图），支持多数据源 160+ 币种实时汇率换算与历史汇率快照。
- **数据导入、导出与加密备份**：支持微信/支付宝/银行账单 CSV、XLSX、JSON 导入，零依赖导出 CSV / XLSX / JSON（可选附带分析文本），以及基于 AES-256-GCM 加密 ZIP 的本地与 WebDAV 备份恢复（兼容旧版明文 JSON）。
- **个性化与系统适配**：提供莫奈动态取色、OLED 纯黑深色模式、动态适配系统亮暗色模式的桌面图标、细粒度触感反馈、DPI 缩放、全局设置搜索高亮与支持国内镜像源的手动检查更新。
