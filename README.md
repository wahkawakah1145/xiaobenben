# 小本本 (XiaoBenBen)

一款基于 Kotlin 与 Jetpack Compose (Material Design 3) 构建的 Android 智能通知记账与多账本管理应用。通过监听系统支付与银行动账通知实现自动解析入账，集成多账本管理与分账本分析、主页选中结果快速分析与多选加入账本、可自定义顺序与显隐的底部 Tab 栏、「账单工具」与「外观与布局」多级菜单、全局及删除撤销横栏停留时长调节（删除提示默认仅手动关闭）、AI理解（本地开源小模型按需下载 / 在线 OpenAI 兼容 API）、OLED 纯黑深色模式与增强型 Material You 动态调色盘、相册选图自定义桌面快捷方式、全维度（年/月/周/日）收支分析、XLSX/CSV 智能表头导入、批量编辑、本地备份、WebDAV 同步与手动 GitHub Release 检查更新等功能。

- **仓库地址**：[https://github.com/wahkawakah1145/xiaobenben](https://github.com/wahkawakah1145/xiaobenben)
- **包名**：`com.live150yo.lvshuiqingshan`
- **开源协议**：MIT License
- **系统支持**：Android 11 (API 30) 及以上 · `targetSdk 37`（Android 17）
- **构建技术栈**：Kotlin · Jetpack Compose (M3) · Room · DataStore · Navigation Compose · OkHttp · Coroutines/Flow

## 核心功能

### 1. 智能通知识别、时间提取与 AI理解
- **全渠道通知自动识别**：监听微信支付、支付宝、云闪付及国内主流银行短信/App 通知，自动识别金额、币种、交易类型（支出 / 收入 / 退款 / 转账）、商户、渠道、卡尾号、分类与 **交易发生时间**（避免通知延迟导致时间偏差），并自动过滤验证码等非账单消息。
- **更聪明的规则自学习**：
  - 点击「非账单」自动生成并启用 **IGNORE 忽略规则**，此后同模板推广/提醒通知直接自动过滤，不再反复弹出询问。
  - 在弹窗中编辑任何带原始通知的账单后，自动按「通知模版签名」写入/覆盖专属模版规则，此后同格式通知均以**最后一次编辑结果**为准进行分类、渠道与商户匹配。
- **AI理解（「设置 -> AI理解」）**：
  - **预设系统提示词查看/编辑/重置 + 规则导入提示词**：内置完整 JSON 结构化解析预设提示词，支持随时编辑、一键重置预设，并可多选自定义识别规则作为参考上下文注入提示词（支持实时预览最终提示词）。
  - **3 档内置推荐开源小模型（由小到大）+ 浏览器权重页 + 自定义权重导入**：支持从 HF-Mirror / HuggingFace 按需下载按体积从小到大排列的 3 档轻量开源模型（`ERNIE-3.0-Nano-Zh` ~130 KB -> `BGE-Small-Zh v1.5` ~560 KB -> `Qwen2.5-0.5B-Instruct` ~7.1 MB），提供一键**打开浏览器下载模型权重网站**按钮，也支持导入自定义 `.gguf` / `.onnx` / `.tflite` / `.safetensors` / `.bin` / `.json` / `.txt` 静态权重或词表文件（严格拦截可执行二进制）。
  - **在线 OpenAI 兼容 API**：支持填入 DeepSeek、硅基流动、通义千问、OpenAI 或自建网关接口地址、API Key 与模型名称。
- **权限管理与低内存后台保活**：在「设置 -> 权限管理」中支持一键快捷打开**本软件的系统权限管理页**（兼容 HyperOS / MIUI 权限页与原生应用详情页），并集中管理通知使用权、无障碍保活守护、电池优化白名单与可选的 **Root (`su`) 进程保活**；内置应用级 `onTrimMemory` 与流式词表扫描机制，在不减弱任何后台保活能力的前提下显著降低空闲内存占用。

### 2. 账单主页、统计维度切换与多范围筛选
- **点击统计卡片切换时间维度**：点击首页统计概览卡片，自由切换 **今日 / 本周 / 本月 / 上月 / 本年 / 全部** 六大时间维度，并可选同步筛选下方账单列表。
- **时间与金额范围筛选 & 跨年日期显式展示**：首页新增可展开的筛选面板，支持时间范围（含日期选择器与快捷时间段）及折算金额下限/上限（含快捷金额筹码）筛选；**非本年账单在分组日期头及列表条目时间戳中自动显示完整年份**（如 `2025年12月20日` / `2025-12-20 09:15`）。
- **多功能 `+` 展开按钮 & 无打扰首页**：移除已运行时的冗余常驻提示磁贴，点击首页 `+` 按钮平滑展开「记一笔」与「识别规则」快捷入口；支持在外观设置中配置位置为左下角或右下角，**双击底部/侧边 Tab 栏**可平滑回到当前页顶部。
- **左对齐自定义顶部品牌栏**：主页顶部支持自定义是否显示应用图标、自定义软件内显示名称与副标题、图标大小/圆角/间距与标题字号粗细，提供简约 SVG 绘图图标并同步桌面图标与莫奈/自定义取色。
- **原始记录可选择复制 & 时间精准编辑**：编辑账单弹窗顶部常驻「原始通知记录」区块，支持长按自由划选及一键复制；所有新增/编辑弹窗均可调整具体发生日期与时间。
- **选中结果快速分析 & 多选加入账本 & 撤销横栏**：长按选中账单或搜索筛选结果后，可点击 **「快速分析」** 弹窗查看折合主币种的收支总额、结余、均价、单笔极值及分类/渠道分布文本（支持一键复制）；底部操作栏支持 **「加入账本」**（多选账本与快速新建）；删除后底部弹出可左右滑关的「撤销恢复」横栏（**默认仅手动关闭**，可在外观设置中按需调整定时消失时长）；首页默认 Tag「我告诉你」，连续点击 7 次弹出彩蛋弹窗。
- **多账本管理与分账本分析**：支持在底部 **「账本」** Tab 或「设置 -> 账单工具 -> 账本管理与分析」中管理多个独立账本（同一账单可同时归属多个账本），支持单账本明细查阅、文本摘要与跳转「收支分析」按账本维度进行图表及日历分析，并完整纳入本地 JSON 与 WebDAV 备份。

### 3. 全粒度收支分析、图例自动折叠与全屏缩放日历
- **年度 / 月 / 周 / 日 四档粒度**：支持自由切换粒度与前翻后翻，全量无精简展示金额、分类及渠道名称，并优化底部维度分析卡片呈现。
- **点击图例查看账单并自动折叠其余图例**：在圆环饼图与对比柱状图模式下点击任意分类或渠道图例，自动展开关联明细并折叠其余未选中图例减少遮挡，配合一键「展开全部图例 / 清除筛选」快捷控制条。
- **双指捏合可调大饼图**：分类占比居中展示大尺寸圆环饼图，支持**双指捏合手势**无级缩放饼图大小（`140dp ~ 300dp`）以隐藏冗余滑块。
- **长距离可调下拉全屏四维缩放日历**：在收支分析顶部大幅下拉（默认距离 `260 dp` 防止日常滚动误触，在「设置 -> 外观与布局 -> 动画、手势与提示横栏」中支持 `80 dp ~ 560 dp` 调节）丝滑全屏弹出交互式 **年 / 月 / 周 / 日** 收支日历（保留底部 Tab 栏），上滑、点击底部极简上箭头图标或切页即可平滑退出，支持**双指捏合缩放手势**切换粒度。

### 4. 外观与布局二级菜单、提示横栏时长与相册快捷方式
「设置 -> 外观与布局」按功能整理为 **5 大二级菜单**，全部支持系统预测性返回与右滑手势返回：
1. **主题与配色**：Android 12+ 开启动态取色时基于系统高纯度 `system_accent1_500` 种子色生成 5 种高辨识度调色板风格（`Tonal Spot` / `Expressive` / `Neutral` / `Vibrant` / `Monochrome`）；深色模式支持 **OLED 纯黑背景 (`#000000`)**；手动调色配备圆形 HSV 色环、HSV/RGB 滑块与常驻 `HEX` 输入框。
2. **字体、DPI 与列表样式**：英文与数字字体切换、全局页面 DPI `0.80x ~ 1.35x`（4 档磁吸 + 精确倍率输入，点击「应用」确认生效）、卡片大小/列表密度、账单行徽标显隐与分类徽标风格。
3. **主页、顶栏与导航**：底部 Tab 排序与隐藏「账本」Tab、主页顶部品牌栏细粒度自定义、金融 Tips 位置/轮换文案自定义、多功能 `+` 按钮位置。
4. **动画、手势与提示横栏**：Tab 切换动画、预测性返回风格、收支分析下拉全屏日历触发距离、**全局提示型底部横栏停留时间**（2s / 4s / 7s / 12s / 仅手动关闭）与**删除后提示横栏停留时间**（独立可调，默认开启「仅手动关闭」）。
5. **图标风格与桌面快捷方式**：6 套 `activity-alias` 图标（含支持壁纸动态取色与 `evenOdd` 镂空的「莫奈徽标」，点选预选并经「应用并重启」确认后切换）；**创建桌面快捷方式**支持权限检测引导、自定义名称、矢量配色，以及**自行选择系统相册图片**（居中圆角裁切与实时预览）作为桌面图标。

### 5. 轻量化安装包、关于与手动检查更新
- **严格控制安装包体积**：极简自绘矢量 `AppIcons` 引擎替代重型扩展图标库，相册选图与 GitHub 更新检查均复用系统原生 API 与已有 `OkHttp` 实现（零新增三方库），配合 Release R8 混淆、日志剔除、资源裁剪与元数据过滤保持极简体积。
- **精简「设置 -> 关于」与手动检查更新**：展示应用图标、版本信息与「检查更新」卡片（手动请求 `GitHub Releases Latest` 接口比对版本号并展示更新日志与 APK 链接，仅支持用户手动更新，无后台轮询）；更新 GitHub 仓库地址至 `wahkawakah1145/xiaobenben`，移除上游项目卡片并将 MIT 开源协议收敛至底部小字展示。

## 本地构建与测试

确保环境已安装 JDK 21 与 Android SDK（通过 `ANDROID_SDK_ROOT` 配置）：

```bash
# 运行全部单元测试与 Robolectric 测试
gradle :app:testDebugUnitTest

# 编译 Debug APK
gradle :app:assembleDebug

# 仅编译 ARMv8 (arm64-v8a) Release APK
gradle :app:assembleRelease -Parmv8Only
```

## GitHub Actions 自动打包签名说明

仓库配置了 `.github/workflows/release-armv8-apk.yml`，在推送 `v*` 标签或手动触发 `workflow_dispatch` 时自动执行单元测试、构建 `arm64-v8a` Release APK（自动注入当前 GitHub 仓库路径用于关于页链接与手动检查更新），并结合 `CHANGELOG.md` 最新章节生成带有更新日志、安装包体积与签名 SHA-256 的 GitHub Release。

签名证书加载优先级：
1. 若仓库配置了 `KEYSTORE_BASE64`、`STORE_PASSWORD` 与 `KEY_PASSWORD` Secrets，则优先使用自定义正式签名证书。
2. 否则自动使用仓库固定签名证书（`.github/ci-release-cert.txt` / `debug.keystore`），确保后续版本与上一版本可直接覆盖升级安装而不发生签名冲突。
