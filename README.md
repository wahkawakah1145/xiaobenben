# 小本本 (XiaoBenBen)

一款基于 Kotlin 与 Jetpack Compose (Material Design 3) 构建的 Android 智能通知记账与多账本管理应用（当前版本 `v1.1.4.527`）。通过监听系统支付、短信、银行及**自定义勾选的手机已安装应用**通知实现秒级自动解析入账，全面支持中文货币单位（如 `10.49新加坡元`、`55.50人民币`）与**多金额通知仅精准提取消费/支出等核心交易金额及对应币种**、杜绝命中规则却返回「未知渠道」的聚合规则引擎；集成默认先加载 100 条（可调 `20 ~ 500 条`）并支持触底上划续载的高流畅度账单主页（全选与反选始终覆盖全部匹配账单，空状态与 `+` 快捷菜单直达导入账单）、账本详情页长按多选批量操作、全局任意删除/移出操作底栏一键撤回、收支分析顶部下拉**跟随手势停动**平滑过渡全屏日历与多样式交互式「趋势图」、非设置页全部小字提示均可单项关闭或一键总控的极简界面、按所选汇率数据源自动覆盖全部币种（ExchangeRate-API 160+ ISO / Currency-API 含数字资产与贵金属 / Frankfurter 31 种 / 自定义数据源按返回值动态添加）、全局可搜索并主题色高亮直达定位的设置系统、带共享卡片过渡动画及右滑/顶部下拉自然返回的独立多账本系统、零依赖流式导出 CSV / XLSX / JSON（可选附带收支分析文本）、支付渠道自动归属（花呗/余额宝 -> 支付宝，零钱/零钱通 -> 微信支付）与动态联动规则/AI 的「渠道管理」、全量现存分类读取与快捷图标编辑、支持删除或转为「不计收支转账」的秒级智能去重、编辑单笔账单按多维条件查找相似账单批量修改、标准 11 列表头与银行流水（含本次余额）账单模型、空格分隔多关键词全维度搜索与日期自动补 `-` / 可选时段筛选、全局多选与「反选」、组合渠道按 `&` 拆分统计与图例列表长按编辑、美化版快速分析弹窗（纯文本复制）、大账本分页防 `CursorWindow` 溢出引擎、AI 严格金额单位防误触、特大号 `🤗` 零位图空状态、OLED 纯黑深色模式与增强型 Material You 动态调色盘、相册选图自定义桌面快捷方式、本地备份、WebDAV 同步与支持国内免费镜像源的手动 GitHub Release 检查更新等功能。

## 核心功能

### 1. 智能通知识别、自定义监听应用、多金额精准提取与 AI理解
- **自定义图形化选择监听应用与主动权限引导（「设置 -> 权限管理 -> 自定义监听应用」/「通知识别与规则」）**：支持图形化勾选手机内已安装的微信、支付宝、短信、各大银行 App 或任意其他应用进行通知监听，支持按名称/包名搜索、按「已勾选 / 推荐金融与短信 / 用户应用 / 系统应用」筛选、一键勾选推荐应用、可选「兜底监听其他应用的强动账通知」开关与手动包名添加；合规通过 `<queries>` 查询桌面及短信应用（不申请 `QUERY_ALL_PACKAGES`），未授权时主动弹窗引导开启通知使用权、通知提醒权限、电池优化白名单与国产系统应用列表权限，应用图标仅在页面内小尺寸懒加载并在离页后立即释放（后台常驻 0 KB）。
- **中文货币单位识别、多金额精准提取与渠道防丢失**：
  - 完整支持前后带中文/外币货币单位（如 `金额10.49新加坡元`、`55.50人民币`、`人民币55.50元`、`新台币`、`澳门币`、`瑞士法郎`、`马币`、`越盾` 等）；当同一通知出现多个金额（如 `发生双信息无卡消费交易，金额10.49新加坡元，已冻结55.50人民币。【中国银行】`，或含 `原价 / 优惠立减 / 折合人民币 / 余额 / 手续费`）时，仅精准识别「支出 / 消费 / 付款 / 扣款 / 实付 / 入账 / 收款」对应的主交易金额及其配对币种；
  - 规则引擎全面优化：兼容全角分隔符 `｜` 与多关键词、聚合所有命中规则的有效渠道（彻底杜绝规则已配置 `中国银行 -> 中国银行` 却被空渠道规则覆盖成「未知渠道」）、支持短信与测试台跨包名关键词匹配，并自动识别 `【花呗 / 余额宝】-> 支付宝`、`【零钱 / 零钱通】-> 微信支付` 及零钱提现/本人转账/信用卡还款不计收支。
- **更聪明的规则自学习与可撤回的「非账单」标记**：
  - 在通知待询问弹窗、首页待确认账单卡片、账单详情页与编辑弹窗中均可一键点击「非账单」，删除误识别记录并自动生成启用的 **IGNORE 忽略规则**，此后同模板推广/提醒通知直接自动过滤；操作后在底栏弹出撤销横栏，点击 **「撤销」** 即可同时恢复原账单（含原所属账本关联）或待确认提醒并自动撤回该忽略规则。
  - 在弹窗中编辑任何带原始通知的账单后，自动按「通知模版签名」写入/覆盖专属模版规则，此后同格式通知均以**最后一次编辑结果**为准进行分类、渠道与商户匹配。
- **AI理解（「设置 -> AI理解」）**：
  - **严格金额单位防误触 + 多金额精准提取**：本地模型、在线 API 及后台通知触发链路均前置显式金额/货币单位校验（支持 `¥ / ￥ / 元 / 块 / 人民币 / 新加坡元 / 美元 / 港元 / 日元 / USD / SGD` 等全量中外货币单位），自动拦截 `[3条]`、`中国移动10086`、`10010`、流量 GB、验证码等无单位裸数字通知，并在多金额通知中仅提取主消费/收支金额及对应币种。
  - **预设系统提示词查看/编辑/重置 + 自定义分类/渠道与规则联动**：内置最新版 JSON 结构化解析预设提示词（动态同步最新自定义分类与渠道列表、多金额精准提取规则、花呗/余额宝/零钱/零钱通渠道归属规则、36+ ISO 货币、秒级时间 `yyyy-MM-dd HH:mm:ss`、严格金额单位校验及零钱提现/本人转账不计收支规则），支持随时编辑（上限 4000 字）、一键重置为最新预设，同时支持多选与**反选**自定义识别规则注入参考上下文。
  - **3 档内置推荐开源小模型（由小到大）+ 浏览器权重页 + 自定义权重导入**：支持从 HF-Mirror / HuggingFace 按需下载按体积从小到大排列的 3 档轻量开源模型（`ERNIE-3.0-Nano-Zh` ~130 KB -> `BGE-Small-Zh v1.5` ~560 KB -> `Qwen2.5-0.5B-Instruct` ~7.1 MB），提供一键**打开浏览器下载模型权重网站**按钮，也支持导入自定义 `.gguf` / `.onnx` / `.tflite` / `.safetensors` / `.bin` / `.json` / `.txt` 静态权重或词表文件（严格拦截可执行二进制）。
  - **在线 OpenAI 兼容 API**：支持填入 DeepSeek、硅基流动、通义千问、OpenAI 或自建网关接口地址、API Key 与模型名称。
- **权限管理、防 `CursorWindow` 溢出与深度后台内存控制**：在「设置 -> 权限管理」中支持一键快捷打开**本软件的系统权限管理页**（兼容 HyperOS / MIUI 权限页与原生应用详情页），集中管理通知使用权、自定义监听应用、无障碍保活守护、电池优化白名单与可选 **Root (`su`) 进程保活**；Room 账单与账本读取全面升级为轻量签名流 + 200 条自适应分片加载（彻底解决超大账本读取偶现 `CursorWindow` 溢出异常），单笔/批量操作改为按 ID 精准直查；无金额单位或未勾选应用的通知在后台直接短路不加载词表与网络；导出引擎全程采用流式 `OutputStream` / `ZipOutputStream` 写入系统存储，不整包驻留内存；全应用统一共享单一 `AppHttpClient`（零常驻核心线程、15 秒自动回收空闲连接与线程）、限制 SQLite 内存页缓存（`512 KB`）与 `wal_autocheckpoint = 200`，在退入后台（`onStop`）及系统 `onTrimMemory` 时自动执行 `PRAGMA shrink_memory` 与连接池/日志/应用名缓存裁剪，在保证后台监听持续活跃的同时显著压低常驻 RAM 占用。

### 2. 吸顶搜索筛选、标准 11 列 + 银行流水模型、多格式导出与智能编辑
- **搜索框与筛选条件滚动自动吸顶常驻**：账单主页与账本详情页的搜索框、范围筛选开关、日期/时段/金额筛选面板与快速分析/导出条均采用不透明 `stickyHeader`，向下滚动列表时自动吸附顶栏常驻，随时调整关键词或筛选区间。
- **标准 11 列与银行流水账单结构**：对照微信/支付宝标准 11 列表头及银行导出格式（新增 `本次余额` 字段，Room v8 无损迁移）完善数据模型，支持在账单详情页查看、记账/编辑弹窗中折叠展开编辑，并完整纳入本地及 WebDAV JSON 备份。
- **空格分隔多关键词搜索、日期自动补全 `-` 与可选时段筛选**：主页与账本详情搜索均支持输入**空格分隔的多个关键词**（全词命中 AND 过滤），同时匹配交易对方、商品、交易类型、当前状态、交易单号/日志号、商户单号、本次余额、分类、拆分后的支付渠道、卡尾号、备注、原始通知、日期、金额及 **36 种币种中英文/缩写**；范围筛选输入日期数字时自动补全 `-`，并支持按 **每日时段**（含跨午夜自定义 `HH:mm` 区间）与折算金额区间组合过滤；非本年账单自动展示完整年份且全局时间精确到秒（`HH:mm:ss`）。
- **零依赖导出 CSV / XLSX / JSON（可选附带收支分析文本）**：在账单主页（筛选条 & 悬浮 `+` 菜单）、账本卡片/详情页与「本地备份」中均支持将当前账单或指定账本导出为 **CSV**（UTF-8 BOM + 可选 `#` 注释分析报告）、原生多工作表 **Excel (.xlsx)**（`账单明细` + 可选独立 `收支分析` 工作表）或 **JSON**（完整结构化数据 + 可选 `analysis.plainText`）。
- **单笔编辑联动相似账单一键更改**：编辑已有账单时可展开「查找相似账单并一键更改」，自由组合交易对方、商品、类型、渠道、分类、方向、金额、币种、卡尾号等单/多条件即时找出全部相似账单（支持勾选、全选与反选），并指定同步字段一键批量修改。
- **全局账单详情所属账本展示与快捷管理**：在主页、账本明细、收支分析图例列表与智能去重等全局全部账单详情弹窗中，均实时展示该笔账单所在账本的彩色徽标，并可点击「添加到账本 / 管理账本」一键调整归属或快捷新建账本。
- **主页分批加载性能优化与全量多选无遗漏**：账单主页默认先加载 **100 条**（可在「设置 -> 外观与布局 -> 主页、顶栏与导航」于 `20 ~ 500 条` 自由调节），滚到底部后上划手势或点击底部条自动续载下一批；日期分组与每日统计前移至记忆化计算、`ThreadLocal` 复用日期格式化器与 `O(1)` 时间戳区间筛选全面降低进出主页与滚动开销；多选模式下的「全选 / 反选」始终覆盖全部匹配账单（包含未加载条目）。
- **全局反选、防遮挡多选布局、美化版「快速分析」与全操作统一撤销横栏**：主页、账本详情页、搜索结果栏、导入预览、智能去重、加入账本与规则选择全面支持 **「反选」**；多选模式下动态加长列表末尾留白避免底部悬浮栏遮盖条目；筛选或多选条目点击「快速分析」展示可视化统计弹窗且复制后仍为纯文本；全局凡涉及删除或移出的操作（删除账单、删除账本、移出账本、删除分类/渠道、删除识别规则、智能去重转转账、标记非账单、忽略提醒、排除去重与移除外币）均在底栏弹出可左右滑关的撤销横栏一键恢复；双击底部/侧边 Tab 栏平滑回到顶部。

### 3. 账单工具（渠道管理、分类图标管理、可选批量导入、多源汇率、可转转账去重与多账本）
- **渠道管理（读取全部现存渠道并动态联动规则与 AI）**（「设置 -> 账单工具 -> 渠道管理」）：与分类管理体验一致（不含图标），自动合并默认/自定义配置、全部历史账单（含 `&` 组合渠道）与识别规则中的全部支付渠道，支持新增、重命名、删除（可撤回）与恢复默认，动态同步历史账单、识别规则与 AI 系统提示词，并内置花呗/余额宝 -> 支付宝、零钱/零钱通 -> 微信支付自动归属规则。
- **分类管理（读取全部现存分类、快捷编辑图标并同步规则与 AI 提示词）**（「设置 -> 账单工具 -> 分类管理」）：自动合并读取默认/自定义列表、全部历史账单与识别规则中的所有现存分类（标注「历史/规则发现」）；支持点击图标徽章或调色按钮为任意分类快捷更换 22 款零依赖矢量图标（全局即时同步并纳入备份）；新增、重命名、删除（可撤回）与恢复默认时自动同步历史账单、识别规则 `defaultCategory` 及 AI 系统提示词。
- **独立高亮入口「从文档或文本导入」（「设置 -> 账单工具 -> 从文档或文本导入」）**：以独立于其他工具选项的卡片样式置顶呈现；完整支持微信/支付宝标准 11 列表头及**农业银行等银行流水导出格式**（如 `交易日期,交易时间,交易摘要,交易金额,本次余额,对手信息,日 志 号,交易渠道,交易附言`），自动按金额正负识别收支并将 `20251121` + `135144` 等数字日期时间智能转换为时间戳；预览列表每条记录均支持**点击切换勾选与长按弹窗查看详情**，默认全选全部正常账单并**自动排除「重复」及「本人互转 / 不计收支」条目**，同时提供全选、反选与一键恢复默认勾选；支持一键读取剪贴板以及可选「启用规则匹配」与「使用 AI 理解」。
- **按所选汇率数据源覆盖全量可选币种 + 自定义数据源自动发现币种**：汇率默认启用最常用的 **5 种外币**（`USD / HKD / EUR / JPY / GBP` + 基准 `CNY`），可选币种自动随所选汇率数据源完整覆盖——**Frankfurter** 覆盖全部 31 种欧洲央行货币、**ExchangeRate-API** 依托系统内置 ICU 覆盖全部 160+ ISO 4217 全球货币、**Currency-API (jsDelivr / Cloudflare)** 额外涵盖主流数字资产与贵金属（如 `BTC / ETH / USDT / XAU` 等）；切换为 **自定义 JSON 汇率链接** 更新后，自动按接口返回的币种键动态添加可选币种，支持中英文/缩写检索添加、移除（可撤回）或一键恢复默认。
- **精确到秒、支持「删除」或「转为不计收支转账」的智能去重**：默认仅判断**金额相同且时间相近**（默认 `1 分钟内`，支持 `10 秒内`、`30 秒内` 及 `秒 / 分 / 时` 自定义），自动按字段信息丰富度评分**保留信息更全的条目、优先处理信息较少的条目**；提供可选 **「交易对象相似」** 开关；对勾选重复项支持 **「删除所选重复」** 或 **「改为不计收支转账」**（保留流水且可一键撤回）；在搜索结果内执行「智能勾选 / 反选 / 取消勾选」仅影响当前筛选条目而不改动其他条目已选状态；支持按单条、整组或批量标记 **「排除智能去重」**（持久化保存并纳入备份，可随时恢复且操作可撤回），长按条目弹出完整详情。
- **多账本独立明细页（长按多选、过渡动画、右滑/顶下拉返回、完整搜索与一键导出）**：点击任意账本卡片以共享元素过渡动画平滑展开独立账本明细页（保留底部 Tab 栏，横滑提示为可关闭的精简提示条位于卡片外下方）；详情页支持与主页相同的吸顶搜索与日期/时段/金额筛选、**长按多选批量操作（快速分析 / 移出本账本 / 加入其他账本 / 批量修改 / 批量删除，均支持撤回）** 及导出账本；**右滑或在列表顶部继续下拉**返回账本主页（再次右滑才切回账单主页），**左滑**直接切入该账本的「收支分析」，横滑回「账本」Tab 仍停留在当前明细页；隐藏底部「账本」Tab 后仍可在账单工具内完整使用。

### 4. 全粒度收支分析、手势跟随过渡日历、交互式「趋势图」与组合渠道拆分
- **年度 / 月 / 周 / 日 四档粒度、组合渠道按 `&` 拆分与图例长按编辑**：全量展示金额、分类及渠道名称；渠道分布自动按 `&`、`+`、`、`、`/` 等符号拆分组合支付方式并支持点击单渠道反查关联账单；点击图例查看对应明细时自动折叠其余未选图例，展开列表支持**单击看详情、长按直接弹出编辑窗**；圆环饼图支持双指捏合无级缩放（`140dp ~ 300dp`）。

## 本地构建与测试

确保环境已安装 JDK 21 与 Android SDK（通过 `ANDROID_SDK_ROOT` 配置）：

```bash
# 运行全部单元测试与 Robolectric 测试
gradle :app:testDebugUnitTest

# Termux 内存受限环境构建/测试参考
gradle :app:testDebugUnitTest --no-daemon --no-configuration-cache --max-workers=2

# 编译 Debug APK
gradle :app:assembleDebug

# 仅编译 ARMv8 (arm64-v8a) Release APK
gradle :app:assembleRelease -Parmv8Only
```

## GitHub Actions 自动打包签名说明

仓库配置了 `.github/workflows/release-armv8-apk.yml`，在推送 `v*` 标签或手动触发 `workflow_dispatch` 时自动执行单元测试、构建 `arm64-v8a` Release APK（自动注入当前 GitHub 仓库路径用于关于页链接与手动检查更新），并结合 `CHANGELOG.md` 最新章节生成带有更新日志、安装包体积与签名 SHA-256 的 GitHub Release。

签名证书加载优先级：
1. 若仓库配置了 `KEYSTORE_BASE64`、`STORE_PASSWORD` 与 `KEY_PASSWORD` Secrets，则优先使用自定义正式签名证书。
2. 否则自动使用仓库固定签名证书（`.github/ci-release-cert.txt` / `debug.keystore`），确保后续版本与上一版本可直接覆盖升级安装而不发生签名冲突。
