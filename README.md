# 小本本 (XiaoBenBen)

一款基于 Kotlin 与 Jetpack Compose (Material Design 3) 构建的 Android 智能通知记账与多账本管理应用（当前版本 `v1.1.4.528`）。通过监听系统支付、短信、银行及**自定义勾选的手机已安装应用**通知实现秒级自动解析入账，全面支持中文货币单位（如 `10.49新加坡元`、`55.50人民币`）、**多金额通知精准提取核心交易金额**、**不含有效金额的通知自动忽略**以及持久化**通知读取日志**（可选条数/时间或无限条数永久保存）；支持**分类与渠道自定义附属关系、长按拖动排序、拖动悬停高光归属、多选一键归属、仅显示父类与一键整合子类**；支持**自定义账单可选信息类别、各大项自由排序、独立折叠进「更多账单信息」与全字段搜索**并动态同步规则与 AI 提示词；支持「**个性化设置**」集成细粒度**触感反馈调节**（跟随系统 / 强度滑块 / 6 场景独立开关）；本地与 WebDAV 备份全面升级为 **AES-256-GCM 加密 ZIP 二进制包**（支持自定义密码并向下兼容旧明文 `.json` 导入），导出 CSV / XLSX / JSON 附带隐私提示；同时内置高流畅度分页账单主页、多账本独立明细与横滑分析、手势跟随日历与交互式趋势图、全局可搜索高亮设置、智能去重、多数据源 160+ 币种汇率、特大号 `🤗` 零位图空状态、OLED 纯黑深色模式与支持国内免费镜像源的手动 GitHub Release 检查更新等功能。

## 核心功能

### 1. 智能通知识别、自定义监听应用、持久化通知日志与 AI理解
- **自定义图形化选择监听应用与可关闭应用列表权限提示（「通知识别与规则 -> 自定义监听手机应用」）**：支持图形化勾选手机内已安装的微信、支付宝、短信、各大银行 App 或任意其他应用，支持搜索、分类筛选、一键勾选推荐应用与手动包名添加；合规通过 `<queries>` 查询桌面及短信应用（不申请 `QUERY_ALL_PACKAGES`），权限管理页与监听应用页统一提供可关闭并记忆的「读取应用列表权限」提示条，点击直达系统应用权限管理页，应用图标离页即释放（后台常驻 0 KB）。
- **持久化通知读取日志 + 无有效金额通知自动忽略（「通知识别与规则 -> 通知读取日志」）**：自动持久化记录每一条读取到的通知，支持按关键词搜索、每页 50 条分页加载、查看完整正文与一键复制，支持自由设置保存条数（`100 / 500 / 2000 / 无限条数`）与保留天数（`7天 / 30天 / 90天 / 永久保存`）；不含有效财务金额的普通通知直接自动忽略不发提醒、不写入待确认弹窗。
- **中文货币单位识别、多金额精准提取与渠道防丢失**：
  - 完整支持前后带中文/外币货币单位（如 `金额10.49新加坡元`、`55.50人民币`、`人民币55.50元`、`新台币`、`澳门币`、`瑞士法郎`、`马币`、`越盾` 等）；当同一通知出现多个金额（如 `发生双信息无卡消费交易，金额10.49新加坡元，已冻结55.50人民币。【中国银行】`）时，仅精准识别「支出 / 消费 / 付款 / 扣款 / 实付 / 入账 / 收款」对应的主交易金额及其配对币种；
  - 规则引擎聚合所有命中规则的有效渠道，杜绝配置了银行规则却返回「未知渠道」；自动支持自定义分类/渠道归属映射与「花呗/余额宝 -> 支付宝」「零钱/零钱通 -> 微信支付」。
- **更聪明的规则自学习与可撤回的「非账单」标记**：
  - 在通知待询问弹窗、首页待确认账单卡片、账单详情页与编辑弹窗中均可一键点击「非账单」，删除误识别记录并自动生成启用的 **IGNORE 忽略规则**，底栏撤销横栏支持一键还原原账单（含所属账本关联）并撤回忽略规则。
  - 编辑任何带原始通知的账单后自动按「通知模版签名」写入/覆盖专属模版规则，此后同格式通知以最后一次编辑结果为准。
- **AI理解（「设置 -> AI理解」）**：
  - **严格金额单位防误触 + 多金额精准提取**：本地模型、在线 API 及后台通知触发链路均前置显式金额/货币单位校验，自动拦截无单位裸数字通知。
  - **预设系统提示词动态联动自定义字段/分类/渠道与规则**：内置最新版 JSON 结构化解析预设提示词，实时同步自定义分类/渠道归属关系与**自定义账单可选信息字段**，支持随时编辑、重置与规则多选/反选参考。
  - **3 档内置推荐开源小模型 + 自定义权重导入 + 在线 OpenAI 兼容 API**：按体积从小到大按需下载轻量权重或接入 DeepSeek / 硅基流动 / 通义千问 / OpenAI 等接口。
- **权限管理、防 `CursorWindow` 溢出与深度后台内存控制**：Room 分页直查与通知日志分页裁剪结合单一共享 `AppHttpClient`、`PRAGMA shrink_memory` 与 `onTrimMemory` 缓存释放，在保证通知监听、无障碍守护与可选 Root (`su`) 保活活跃的前提下控制后台 RAM 占用。

### 2. 吸顶搜索筛选、标准 11 列 + 银行流水模型、多格式导出与智能编辑
- **搜索框与筛选条件滚动自动吸顶常驻**：账单主页与账本详情页的搜索框、范围筛选开关、日期/时段/金额筛选面板与快速分析/导出条均采用不透明 `stickyHeader`，向下滚动列表时自动吸附顶栏常驻，随时调整关键词或筛选区间。
- **标准 11 列与银行流水账单结构**：对照微信/支付宝标准 11 列表头及银行导出格式（新增 `本次余额` 字段，Room v8 无损迁移）完善数据模型，支持在账单详情页查看、记账/编辑弹窗中折叠展开编辑，并完整纳入本地及 WebDAV JSON 备份。
- **空格分隔多关键词搜索、日期自动补全 `-` 与可选时段筛选**：主页与账本详情搜索均支持输入**空格分隔的多个关键词**（全词命中 AND 过滤），同时匹配交易对方、商品、交易类型、当前状态、交易单号/日志号、商户单号、本次余额、分类、拆分后的支付渠道、卡尾号、备注、原始通知、日期、金额及 **36 种币种中英文/缩写**；范围筛选输入日期数字时自动补全 `-`，并支持按 **每日时段**（含跨午夜自定义 `HH:mm` 区间）与折算金额区间组合过滤；非本年账单自动展示完整年份且全局时间精确到秒（`HH:mm:ss`）。
- **零依赖导出 CSV / XLSX / JSON（附明文隐私提示 + 可选收支分析文本）**：在账单主页、账本卡片/详情页与「本地备份」中支持一键导出 **CSV**、原生多工作表 **Excel (.xlsx)** 或 **JSON**，并在导出弹窗展示醒目的明文文件隐私保护提醒。
- **加密 ZIP 备份与旧明文兼容恢复（「设置 -> 备份与恢复」）**：本地备份与 WebDAV 同步统一将完整账本、规则、设置与自定义字段打包为 **AES-256-GCM + PBKDF2 加密 ZIP 压缩包**（支持自定义加密密码与防路径穿越校验），同时无缝兼容恢复早期明文 `.json` 备份文件。
- **单笔编辑联动相似账单一键更改 & 全局账单详情所属账本快捷管理**：支持按多维特征筛选相似账单批量修改，在任意页面详情弹窗查看并调整所属账本。
- **主页分批加载性能优化与全量多选无遗漏**：账单主页默认先加载 **100 条**（可在「设置 -> 个性化设置 -> 主页、顶栏与导航」于 `20 ~ 500 条` 自由调节），滚到底部后上划续载，多选「全选 / 反选」始终覆盖全部匹配账单；全局所有删除与移出操作均支持底栏一键撤销。

### 3. 账单工具（分类/渠道归属排序、账单可选字段、批量导入、多源汇率、智能去重与多账本）
- **分类管理与渠道管理（自定义附属关系、长按拖动排序/拖放高光归属、多选一键归属与一键整合）**：自动读取默认/自定义配置、历史账单与规则中的全量分类与渠道；支持长按拖动排序、将 A 项拖到 B 项上高光显示时松手归属进 B 项、多选一键批量归属或解除归属；支持切换 **「显示全部子类 / 仅显示父类」** 与 **「一键整合子类到父类」**，并动态同步规则与 AI 系统提示词（分类管理同步支持 22 款快捷矢量图标编辑）。
- **账单信息与可选字段管理（「设置 -> 账单工具 -> 账单信息与可选字段」）**：支持对账单各大项（金额、商户、渠道、分类、账本、时间等）与可选字段（商品、类型、状态、余额、单号、备注、卡尾号及用户自定义新增字段）长按拖动排序；支持自定义新增/重命名/启停可选信息类别、逐项配置是否折叠进「更多账单信息」，并自动同步规则、AI 提示词与全字段搜索。
- **独立高亮入口「从文档或文本导入」（「设置 -> 账单工具 -> 从文档或文本导入」）**：支持微信/支付宝 11 列表头与农业银行等银行流水表头，预览勾选/长按详情，默认排除重复与本人互转。
- **按所选汇率数据源覆盖全量可选币种 + 自定义数据源自动发现币种**：Frankfurter 31 种 / ExchangeRate-API 160+ ISO / Currency-API 含主流数字资产与贵金属 / 自定义链接自动解析返回币种。
- **精确到秒、支持「删除」或「转为不计收支转账」的智能去重**：金额+时间默认聚类、信息丰富度优先保留、搜索范围独立批量勾选与持久化「排除智能去重」。
- **多账本独立明细页**：共享卡片过渡动画、吸顶搜索与筛选、长按多选批量操作、右滑/顶下拉自然返回账本主页、左滑直达该账本收支分析与一键导出。

### 4. 全粒度收支分析、手势跟随过渡日历、交互式「趋势图」与组合渠道拆分
- **年度 / 月 / 周 / 日 四档粒度、父级归属联动与组合渠道按 `&` 拆分**：自动遵守分类/渠道「仅显示父类 / 显示全部子类」偏好；图例明细支持单击看详情、长按直接编辑；圆环饼图支持双指缩放。
- **顶部下拉「跟随手势停动」过渡进入全屏四维缩放日历 + 多样式交互式「趋势图」**：支持柱状图 / 折线图 / 面积图切换与按住滑动精确读数。

### 5. 全局设置搜索高亮、个性化设置（含触感反馈）与国内镜像更新
- **设置项全局搜索与主题色高亮定位**：精简搜索框为 `搜索设置项`，支持中文/英文关键词直达对应二级/三级设置页并以主题主色高亮标记目标项。
- **个性化设置 5 大二级菜单**（原「外观与布局」，支持预测性返回与右滑手势）：
  1. **主题与配色**：Android 12+ 动态取色 5 种调色盘、OLED 纯黑背景、HSV 色环与 HEX 调色。
  2. **字体、DPI 与列表样式**：英文与数字字体、全局 DPI `0.80x ~ 1.35x`、卡片密度与徽标样式。
  3. **主页、顶栏与导航**：底部 Tab 排序与隐藏「账本」、首页单次加载条数、功能提示管理（含「读取应用列表权限」在内的全部非设置页功能提示一键开关）、顶栏品牌、Tips 与 `+` 菜单位置。
  4. **触感反馈、动画与手势**：新增**细粒度触感反馈**（总开关、跟随系统触感、自定义强度滑块 + 预设档位、6 场景独立开关与实时试振），以及 Tab 动画、预测性返回风格、全局与撤销横栏停留策略。
  5. **图标风格与桌面快捷方式**：6 套 `activity-alias` 图标与相册选图自定义桌面快捷方式。
- **严格控制安装包体积与国内镜像检查更新**：零新增第三方依赖与位图资源，支持 GitHub 官方直连或国内免费镜像源手动检查 Release 并下载 APK。

## GitHub Actions 自动打包签名说明

仓库配置了 `.github/workflows/release-armv8-apk.yml`，在推送 `v*` 标签或手动触发 `workflow_dispatch` 时自动执行单元测试、构建 `arm64-v8a` Release APK（自动注入当前 GitHub 仓库路径用于关于页链接与手动检查更新），并结合 `CHANGELOG.md` 最新章节生成带有更新日志、安装包体积与签名 SHA-256 的 GitHub Release。

签名证书加载优先级：
1. 若仓库配置了 `KEYSTORE_BASE64`、`STORE_PASSWORD` 与 `KEY_PASSWORD` Secrets，则优先使用自定义正式签名证书。
2. 否则自动使用仓库固定签名证书（`.github/ci-release-cert.txt` / `debug.keystore`），确保后续版本与上一版本可直接覆盖升级安装而不发生签名冲突。
