# 小本本 (XiaoBenBen)

一款基于 Kotlin 与 Jetpack Compose (Material Design 3) 构建的 Android 智能通知记账与多账本管理应用（当前版本 `v1.1.4.523`）。通过监听系统支付与银行动账通知实现秒级自动解析入账，集成点击直达独立明细并可横滑无缝切入该账本收支分析的多账本系统、全局账单详情展示所属账本与一键加入账本、全量现存分类读取与快捷图标编辑（自动同步账单/识别规则/AI 提示词）、编辑单笔账单时按多维条件查找相似账单并一键批量更改、标准 11 列表头与银行流水（含本次余额）账单模型、空格分隔多关键词全维度搜索与日期自动补 `-` / 可选时段筛选、全局多选与「反选」、36+ 币种中英文/缩写检索与多源/自定义汇率更新、「账单工具」独立高亮入口「从文档或文本导入」（可选勾选、长按详情、智能排除重复与本人互转，支持农业银行等银行格式与数字智能转时间戳）、组合渠道按 `&` 拆分统计与图例列表长按编辑、美化版快速分析弹窗（纯文本复制）、账单/规则删除及「标记非账单」底栏一键撤回、大账本分页防 `CursorWindow` 溢出引擎、支持搜索范围独立勾选与持久化「排除去重」的秒级智能去重、AI 严格金额单位防误触、月历每日双行收支展示、可自定义顺序与显隐的底部 Tab 栏、OLED 纯黑深色模式与增强型 Material You 动态调色盘、相册选图自定义桌面快捷方式、本地备份、WebDAV 同步与支持国内免费镜像源的手动 GitHub Release 检查更新等功能。

## 核心功能

### 1. 智能通知识别、秒级时间提取与 AI理解
- **全渠道通知自动识别与内部转账不计收支**：监听微信支付、支付宝、云闪付及国内主流银行短信/App 通知，自动识别金额、36 种常见货币、交易类型、商户、渠道、卡尾号、分类与 **精确到秒的交易发生时间**（`HH:mm:ss`）；**微信/支付宝零钱提现、提现到银行卡、零钱通/余额宝互转、本人转账/同名账户互转与信用卡还款自动识别为「转账 / 不计收支」**，避免虚增日常收支。
- **更聪明的规则自学习与可撤回的「非账单」标记**：
  - 在通知待询问弹窗、首页待确认账单卡片、账单详情页与编辑弹窗中均可一键点击「非账单」，删除误识别记录并自动生成启用的 **IGNORE 忽略规则**，此后同模板推广/提醒通知直接自动过滤；操作后在底栏弹出撤销横栏，点击 **「撤销」** 即可同时恢复原账单（含原所属账本关联）或待确认提醒并自动撤回该忽略规则。
  - 在弹窗中编辑任何带原始通知的账单后，自动按「通知模版签名」写入/覆盖专属模版规则，此后同格式通知均以**最后一次编辑结果**为准进行分类、渠道与商户匹配。
- **AI理解（「设置 -> AI理解」）**：
  - **严格金额单位防误触（不识别无单位裸数字）**：本地模型、在线 API 及后台通知触发链路均前置显式金额/货币单位校验（仅接受带 `¥ / ￥ / 元 / 块 / 人民币 / $ / USD / HKD` 等明确货币单位的金额），自动拦截 `[3条]`、`中国移动10086`、`10010`、流量 GB、验证码等裸数字通知，既避免误记账又省去无效后台扫描与网络请求。
  - **预设系统提示词查看/编辑/重置 + 自定义分类与规则联动**：内置最新版 JSON 结构化解析预设提示词（动态同步最新自定义分类列表、36+ ISO 货币、秒级时间 `yyyy-MM-dd HH:mm:ss`、严格金额单位校验及零钱提现/本人转账不计收支规则），支持随时编辑（上限 4000 字）、一键重置为最新预设，同时支持多选与**反选**自定义识别规则注入参考上下文。
  - **3 档内置推荐开源小模型（由小到大）+ 浏览器权重页 + 自定义权重导入**：支持从 HF-Mirror / HuggingFace 按需下载按体积从小到大排列的 3 档轻量开源模型（`ERNIE-3.0-Nano-Zh` ~130 KB -> `BGE-Small-Zh v1.5` ~560 KB -> `Qwen2.5-0.5B-Instruct` ~7.1 MB），提供一键**打开浏览器下载模型权重网站**按钮，也支持导入自定义 `.gguf` / `.onnx` / `.tflite` / `.safetensors` / `.bin` / `.json` / `.txt` 静态权重或词表文件（严格拦截可执行二进制）。
  - **在线 OpenAI 兼容 API**：支持填入 DeepSeek、硅基流动、通义千问、OpenAI 或自建网关接口地址、API Key 与模型名称。
- **权限管理、防 `CursorWindow` 溢出与深度后台内存控制**：在「设置 -> 权限管理」中支持一键快捷打开**本软件的系统权限管理页**（兼容 HyperOS / MIUI 权限页与原生应用详情页），集中管理通知使用权、无障碍保活守护、电池优化白名单与可选 **Root (`su`) 进程保活**；Room 账单与账本读取全面升级为轻量签名流 + 200 条自适应分片加载（彻底解决超大账本读取偶现 `CursorWindow` 溢出异常），单笔/批量操作改为按 ID 精准直查；无金额单位通知在后台直接短路不加载词表与网络；全应用统一共享单一 `AppHttpClient`（零常驻核心线程、15 秒自动回收空闲连接与线程）、限制 SQLite 内存页缓存（`512 KB`）与 `wal_autocheckpoint = 200`，在退入后台（`onStop`）及系统 `onTrimMemory` 时自动执行 `PRAGMA shrink_memory` 与连接池/日志裁剪，在保证后台监听持续活跃的同时显著压低常驻 RAM 占用。

### 2. 标准 11 列 + 银行流水模型、多关键词筛选与智能编辑
- **标准 11 列与银行流水账单结构**：对照微信/支付宝标准 11 列表头及银行导出格式（新增 `本次余额` 字段，Room v8 无损迁移）完善数据模型，支持在账单详情页查看、记账/编辑弹窗中折叠展开编辑，并完整纳入本地及 WebDAV JSON 备份。
- **空格分隔多关键词搜索、日期自动补全 `-` 与可选时段筛选**：首页搜索支持输入**空格分隔的多个关键词**（全词命中 AND 过滤），同时匹配交易对方、商品、交易类型、当前状态、交易单号/日志号、商户单号、本次余额、分类、拆分后的支付渠道、卡尾号、备注、原始通知、日期、金额及 **36 种币种中英文/缩写**；范围筛选输入日期数字时自动补全 `-`，并支持按 **每日时段**（含跨午夜自定义 `HH:mm` 区间）与折算金额区间组合过滤；非本年账单自动展示完整年份且全局时间精确到秒（`HH:mm:ss`）。
- **单笔编辑联动相似账单一键更改**：编辑已有账单时可展开「查找相似账单并一键更改」，自由组合交易对方、商品、类型、渠道、分类、方向、金额、币种、卡尾号等单/多条件即时找出全部相似账单（支持勾选、全选与反选），并指定同步字段一键批量修改。
- **全局账单详情所属账本展示与快捷管理**：在主页、账本明细、收支分析图例列表与智能去重等全局全部账单详情弹窗中，均实时展示该笔账单所在账本的彩色徽标，并可点击「添加到账本 / 管理账本」一键调整归属或快捷新建账本。
- **全局反选、防遮挡多选布局、美化版「快速分析」与统一撤销横栏**：首页多选操作栏、搜索结果栏、导入预览、智能去重、加入账本与规则选择全面支持 **「反选」**；多选模式下动态加长列表末尾留白避免底部悬浮栏遮盖条目；筛选或多选条目点击「快速分析」展示可视化统计弹窗且复制后仍为纯文本；删除账单、删除识别规则或标记「非账单」后均在底栏弹出可左右滑关的撤销横栏；双击底部/侧边 Tab 栏平滑回到顶部。

### 3. 账单工具（全量分类图标管理、可选批量导入、多源汇率、搜索独立去重与多账本联动）
- **分类管理（读取全部现存分类、快捷编辑图标并同步规则与 AI 提示词）**（「设置 -> 账单工具 -> 分类管理」）：自动合并读取默认/自定义列表、全部历史账单与识别规则中的所有现存分类（标注「历史/规则发现」）；支持点击图标徽章或调色按钮为任意分类快捷更换 22 款零依赖矢量图标（全局即时同步并纳入备份）；新增、重命名、删除与恢复默认时自动同步历史账单、识别规则 `defaultCategory` 及 AI 系统提示词。
- **独立高亮入口「从文档或文本导入」（「设置 -> 账单工具 -> 从文档或文本导入」）**：以独立于其他工具选项的卡片样式置顶呈现；完整支持微信/支付宝标准 11 列表头及**农业银行等银行流水导出格式**（如 `交易日期,交易时间,交易摘要,交易金额,本次余额,对手信息,日 志 号,交易渠道,交易附言`），自动按金额正负识别收支并将 `20251121` + `135144` 等数字日期时间智能转换为时间戳；预览列表每条记录均支持**点击切换勾选与长按弹窗查看详情**，默认全选全部正常账单并**自动排除「重复」及「本人互转 / 不计收支」条目**，同时提供全选、反选与一键恢复默认勾选；支持一键读取剪贴板以及可选「启用规则匹配」与「使用 AI 理解」。
- **默认 5 种常用外币汇率按需扩展 + 多源/自定义链接**：汇率默认启用最常用的 **5 种外币**（`USD / HKD / EUR / JPY / GBP` + 基准 `CNY`），其余 30+ 全球货币支持通过英文缩写或中文别名按需搜索添加、随时移除或一键恢复默认；汇率更新支持切换 **ExchangeRate-API**、**Currency-API (jsDelivr CDN / Cloudflare Pages)**、**Frankfurter (欧洲央行)** 或填写 **自定义 JSON 汇率链接**。
- **精确到秒、搜索范围独立勾选与可排除的智能去重**：默认仅判断**金额相同且时间相近**（默认 `1 分钟内`，支持 `10 秒内`、`30 秒内` 及 `秒 / 分 / 时` 自定义），自动按字段信息丰富度评分**保留信息更全的条目、优先删除信息较少的条目**；提供可选 **「交易对象相似」** 开关；在搜索结果内执行「智能勾选 / 反选 / 取消勾选」仅影响当前筛选条目而不改动其他条目已选状态；支持按单条、整组或批量标记 **「排除智能去重」**（持久化保存并纳入备份，可随时在「已排除去重」弹窗中恢复），长按条目弹出完整详情。
- **多账本独立明细页（横滑无缝分析）与数据空间优化**：点击任意账本卡片即进入独立账本明细页（保留底部 Tab 栏），直接横滑至「收支分析」Tab 自动分析当前账本，横滑回「账本」Tab 仍停留在当前明细页，返回操作退回账本主页；隐藏底部「账本」Tab 后仍可在账单工具内完整使用；内置 SQLite `VACUUM` 压缩、缓存清理与历史通知正文精简。

### 4. 全粒度收支分析、组合渠道拆分与月历双行收支视图
- **年度 / 月 / 周 / 日 四档粒度、组合渠道按 `&` 拆分与图例长按编辑**：全量展示金额、分类及渠道名称；渠道分布自动按 `&`、`+`、`、`、`/` 等符号拆分组合支付方式（如 `花呗&红包&现金抵价券` 分别记入各子渠道统计并支持点击单渠道反查关联账单）；点击图例查看对应明细时自动折叠其余未选图例，展开列表支持**单击看详情、长按直接弹出编辑窗**；圆环饼图支持双指捏合无级缩放（`140dp ~ 300dp`）。
- **长距离可调下拉全屏四维缩放日历（左右横滑切周期）**：在收支分析顶部下拉（默认 `260 dp`，支持 `80 ~ 560 dp` 调节）弹出交互式 **年 / 月 / 周 / 日** 日历（双指捏合切换粒度）；**进入日历后锁定底部 Tab 滑动，左右横滑手势直接切换年份 / 月份 / 周次 / 日期**；月视图顶部含当月汇总条，每日单元格同时展示支出与收入双行金额。

### 5. 外观与布局二级菜单、轻量化体积与国内镜像更新
- **外观与布局 5 大二级菜单**（支持预测性返回与右滑手势）：
  1. **主题与配色**：Android 12+ 动态取色 5 种高辨识度调色盘（`Tonal Spot` / `Expressive` / `Neutral` / `Vibrant` / `Monochrome`）、深色模式 **OLED 纯黑背景 (`#000000`)**、圆形 HSV 色环与常驻 HEX 调色。
  2. **字体、DPI 与列表样式**：英文与数字字体、全局 DPI `0.80x ~ 1.35x`（点击「应用」确认生效）、卡片密度与徽标样式。
  3. **主页、顶栏与导航**：底部 Tab 排序与隐藏「账本」Tab、顶栏品牌自定义、金融 Tips 定制与 `+` 按钮位置。
  4. **动画、手势与提示横栏**：Tab 动画、预测性返回风格、下拉全屏日历距离、全局底部提示横栏停留时间，以及精简后的 **删除后提示横栏「仅手动关闭」单开关**（关闭后自动跟随全局时长）。
  5. **图标风格与桌面快捷方式**：6 套 `activity-alias` 图标（含动态莫奈徽标）与支持**系统相册选图**（居中圆角裁切）的自定义桌面快捷方式。
- **严格控制安装包体积与国内镜像检查更新**：全部新特性（36 种货币、多汇率源、GitHub 镜像、秒级去重与增强导入）零新增第三方依赖，继续保持轻量化 ARMv8 Release 构建；在「设置 -> 关于 -> 版本更新」中支持选择 **GitHub 官方直连** 或 **国内免费镜像源**（`akams.cn` / `gh-proxy.com` / `ghproxy.net`）手动检查 Release 并加速下载 APK。

## GitHub Actions 自动打包签名说明

仓库配置了 `.github/workflows/release-armv8-apk.yml`，在推送 `v*` 标签或手动触发 `workflow_dispatch` 时自动执行单元测试、构建 `arm64-v8a` Release APK（自动注入当前 GitHub 仓库路径用于关于页链接与手动检查更新），并结合 `CHANGELOG.md` 最新章节生成带有更新日志、安装包体积与签名 SHA-256 的 GitHub Release。

签名证书加载优先级：
1. 若仓库配置了 `KEYSTORE_BASE64`、`STORE_PASSWORD` 与 `KEY_PASSWORD` Secrets，则优先使用自定义正式签名证书。
2. 否则自动使用仓库固定签名证书（`.github/ci-release-cert.txt` / `debug.keystore`），确保后续版本与上一版本可直接覆盖升级安装而不发生签名冲突。
