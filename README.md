# 小本本 (XiaoBenBen)

> 一款专注**无感通知自动记账**与**多账本精细管理**的 Android 原生记账应用，基于 Kotlin 与 Jetpack Compose (Material Design 3) 打造，兼顾轻量体积、离线隐私与高自由度定制。

## 核心功能一览

### 1. 智能通知监听与精准解析
- **自由选择监听应用**：支持图形化勾选手机内任意已安装应用（微信、支付宝、短信、各大银行及消费类 App），仅针对选定应用执行解析与日志记录。
- **宽覆盖金额与多金额精准提取**：内置覆盖中外币种、中文前后缀单位（如 `人民币元 2,000.00`、`10.49新加坡元`）及银行汇款/扣划/消费/入账/退费等动账词库的规则引擎；单条通知含多个金额时自动按上下文提取主交易金额，忽略余额、额度、冻结与原价干扰；不含有效金额的通知自动静默忽略。
- **自定义规则与非账单过滤**：支持关键词/正则/模版自定义识别规则、渠道自动归属（如花呗/余额宝→支付宝，零钱/零钱通→微信支付）、自定义非账单忽略规则，以及待确认询问弹窗自动反哺学习。
- **持久化通知读取日志**：完整留存监听应用通知记录，支持关键词搜索、分页懒加载、自定义保留条数（`100 / 500 / 2000 / 无限`）与保留时长（`7天 / 30天 / 90天 / 永久`）；任意历史通知均可在列表卡片或详情页自由选择 **「规则识别」** 或 **「AI 识别」** 重新解析并补录入账。

### 2. 端侧大模型（GGUF）与在线 AI 增强
- **原生端侧 GGUF 推理与按需下载**：集成轻量 `arm64-v8a` 原生 `llama.cpp` 推理引擎，自动校验 GGUF v2/v3 权重头；内置 `ERNIE 3.0 Nano`、`Qwen2.5-0.5B-Instruct` 轻量词表包与 ≤350MB 端侧大模型 **`LiquidAI LFM2.5-350M (Q4_K_M, ~229MB)`**，支持 HF-Mirror 国内加速源、HuggingFace 官方源及手动导入本地 `.gguf / .onnx / .tflite / .json` 权重。
- **在线接口与折叠参考规则**：支持 OpenAI 兼容自定义 API 与「仅规则未命中时兜底」策略，自动同步用户的分类体系、渠道归属与自定义账单字段至提示词，支持折叠式勾选参考识别规则。
- **调参与对话测试**：在「AI理解」菜单底部提供 **「调参与测试」** 子菜单，支持调节 `Temperature`、`Top-P`、`Top-K`、`最大输出 Token`、`上下文长度`、`CPU 线程数`、`Seed` 与空闲自动释放策略，支持多轮**对话测试**、账单解析实测、模型预加载校验与一键释放内存。

### 3. 账单管理与独立多账本
- **流畅账单主页**：支持吸顶常驻搜索栏（支持日期、时段、金额区间、分类/渠道父子项及全部扩展字段搜索）、可调单次分批加载条数、长按多选批量修改/删除、相似账单联动更新与全局删除/修改一键撤回。
- **多账本独立管理**：支持创建多个带主题色的独立账本，支持卡片过渡动画与手势返回、账本内搜索与长按多选、跨账本关联及专属收支统计。
- **智能去重**：自动检测重复入账记录，可按需选择一键删除重复项或转为不计收支的内部转账。

### 4. 分类、渠道与账单字段全定制
- **父子归属与拖放管理**：分类与渠道均支持父子层级折叠管理，支持长按跨项拖动排序、悬停停顿高光直接拖放归属、多选一键归属与快捷查看关联账单（含子类/仅本项筛选）。
- **无损显示切换与图标定制**：支持在账单与统计中无损切换「显示子类名 / 显示父类名」（不改动原始记录），支持自定义分类图标及全操作撤销。
- **自定义账单信息字段**：支持自定义账单可选信息类别（商品、交易类型、状态、余额、单号、备注及用户扩展字段），支持各大项排序、按项折叠进「更多账单信息」并参与全局搜索。

### 5. 多维度收支分析与全球汇率
- **可视化报表与趋势图**：支持年/月/周/日多维度汇总、分类/渠道圆环占比、手势跟随无缝下拉进入全屏收支日历，以及支持柱状图/折线图/面积图切换与长按滑动查看坐标的交互式趋势图。
- **多数据源实时汇率**：覆盖所选数据源全部 160+ 币种，支持自定义汇率接口自动发现币种、多币种自动折算与单笔交易历史汇率快照。

### 6. 数据导入、导出与加密备份
- **多格式导入与导出**：支持微信、支付宝、银行账单 `CSV / XLSX / JSON` 导入；零额外依赖导出 `CSV / XLSX / JSON`（可选附带统计分析文本，并内置明文文件隐私提示）。
- **AES-256-GCM 加密备份**：本地备份与 WebDAV 同步统一采用加密 ZIP 二进制封装（可选自定义密码，向下兼容旧版明文 JSON 导入），并提供定时备份提醒与一键存储空间清理。

### 7. 个性化外观与轻量后台保活
- **视觉与交互定制**：支持 Material You 莫奈动态取色、自定义主题调色板、OLED 纯黑深色模式、6 套亮暗色自适应高对比度统一图标（桌面图标与设置预览完全一致，支持相册图快捷方式）、细粒度触感反馈、DPI 缩放、可开关功能提示及全局设置搜索定位高亮。
- **体积与内存控制**：严格控制安装包体积，端侧 GGUF 采用按需懒加载 + 单飞互斥 + 空闲自动卸载 + 系统内存压力即时回收机制，在保障通知监听、无障碍守护与 Root 保活服务稳定运行的前提下最小化后台内存占用；内置支持国内镜像源的 GitHub Release 手动检查更新。
